## 5. Reporting Lines

For SMALL tier the reporting structure adds a part-time CISO
function (or external advisor) and a founder DPO:

```
                ┌───────────────────┐
                │   Founders (CEO)  │
                └─────────┬─────────┘
                          │
        ┌─────────────────┼──────────────────────┐
        │                 │                      │
   ┌────▼─────┐    ┌──────▼───────┐    ┌─────────▼────────┐
   │ CTO      │    │  Founder DPO │    │  Part-time CISO  │
   │          │    │  (Art. 37(2))│    │  or Advisor      │
   └────┬─────┘    └──────────────┘    └──────────────────┘
        │
   ┌────▼─────┐
   │ Engineers│
   └──────────┘
```

## 7. Training Status

For SMALL tier: annual security briefing for all staff; GDPR
awareness module for those handling personal data. Annual phishing
simulation recommended; not yet mandatory for all SMEs.

## 9. Gaps and Known Limitations

- Part-time CISO function limits 24/7 incident coverage
- GDPR Art. 37(2) DPO independence must be documented in case of
  conflict of interest
- Awareness programme gaps should be tracked and uplifted before
  crossing the MEDIUM threshold (50 employees)
