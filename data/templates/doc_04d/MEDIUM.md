## 5. Reporting Lines

For MEDIUM tier the reporting structure establishes a dedicated
CISO and an external DPO advisor:

```
                ┌───────────────────┐
                │    CEO / Board    │
                └─────────┬─────────┘
                          │
        ┌─────────────────┼──────────────────────┐
        │                 │                      │
   ┌────▼─────┐    ┌──────▼───────┐    ┌─────────▼────────┐
   │ CTO      │    │ Compliance   │    │ External DPO     │
   │          │    │   Lead       │    │   Advisor        │
   └────┬─────┘    └──────┬───────┘    └──────────────────┘
        │                 │
   ┌────▼─────┐    ┌──────▼───────┐
   │ CISO     │    │ Obligation   │
   │(dedicated)│   │  Register    │
   └──────────┘    └──────────────┘
```

## 7. Training Status

For MEDIUM tier: annual e-learning + monthly micro-learning; quarterly
phishing simulation; role-based training for engineers and finance.

## 9. Gaps and Known Limitations

- DPO independence relies on external advisor — transition to dedicated
  in-house DPO required if sensitive processing at scale (GDPR Art. 37(1)(c))
- NIS2 24h early-warning workflow requires dedicated on-call rotation —
  not yet established at MEDIUM scale
- ISO 27001 certification deferred; ISMS documented and operational
  but not externally certified
