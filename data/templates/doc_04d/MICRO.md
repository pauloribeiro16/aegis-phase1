## 5. Reporting Lines

For MICRO tier the reporting structure is flat:

```
                ┌──────────────────┐
                │     Founder      │
                └────────┬─────────┘
                         │
        ┌────────────────┼─────────────────┐
        │                │                 │
   ┌────▼─────┐    ┌─────▼─────┐    ┌─────▼──────┐
   │ Engineer │    │  Founder  │    │ External   │
   │ (ops)    │    │   DPO     │    │ Advisor    │
   └──────────┘    └───────────┘    └────────────┘
```

There is no dedicated CISO. Security and privacy responsibilities
rest with the founder; an external advisor may be engaged on
demand per GDPR Art. 37(2).

## 7. Training Status

For MICRO tier: ad-hoc security briefing during onboarding; no
formal awareness programme. Annual phishing simulation not expected.

## 9. Gaps and Known Limitations

- No dedicated security function; documented intent to scale with
  headcount
- Founder DPO capacity must be monitored — once sensitive data is
  processed at scale, a dedicated DPO is mandatory per GDPR Art. 37(1)
- Awareness programme gaps acceptable while headcount < 10
