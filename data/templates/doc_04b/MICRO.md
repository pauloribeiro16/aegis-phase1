# Maturity Consistency Template for MICRO tier

## 6. Consistency Check (Maturity)

For MICRO entities the maturity profile is intentionally compressed:

- Current: 1 across all ten domains (D-01..D-10) — controls are
  ad-hoc / informal. Acceptable for a sub-10-employee entity.
- Target: 2 for security-critical domains (D-01 data protection,
  D-02 vulnerability, D-03 access, D-04 IR, D-07 secure dev, D-09
  governance). Target 1 for domains where formalisation is not
  proportionate (D-05 lifecycle, D-06 third-party, D-08 human
  factors, D-10 monitoring).

This profile aligns with the role-models/MICRO.yaml expectation:
founder + part-time engineer; no dedicated security function.

**Gate Status:** PASS — proportionate for MICRO under P2.
