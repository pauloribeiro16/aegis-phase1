## 3. Helper novo: `_downgrade_headers(md_text) -> str`

Rebaixa todos os headers Markdown 1 nível: `#` → `##`, `##` → `###`, ..., `######` → `#######`.

**Implementação:**
```python
def _downgrade_headers(md_text: str) -> str:
    """Rebaixa todos os headers Markdown (# ... ######) um nível."""
    out = []
    for line in md_text.split("\n"):
        m = re.match(r"^(#{1,6})(\s)", line)
        if m:
            out.append("#" + line)  # prepend one #
        else:
            out.append(line)
    return "\n".join(out)
```
Só toca linhas que começam com 1-6 `#` seguidos de espaço. Não afeta tabelas, code blocks, ou texto que contenha `#` no meio. Risco baixíssimo.

## 4. MUDANÇA 2 — Ambiguidade extraída por secção (many-to-many)

Esta é a parte delicada. Precisas de 2 parsers + 1 inversão.

### 4a. Parser A: `clause_id → set(sub_domain)` a partir de `02_SecurityRules_NIST.md`

**Fonte:** `methodology-00/PREPROCESSING/Regulation/{REG}/02_SecurityRules_NIST.md` (existe para as 5 regs).

**Estrutura do ficheiro (YAML em fenced blocks):**
```yaml
## D-01 — Data Protection & Encryption

### SO-GDPR-001 / SO-GDPR-014 (CIA + resilience)


```yaml
- sr_id: SR-GDPR-001
  title: "CIA + resilience baseline for personal data processing"
  source_clauses:
    - { clause_id: GDPR-CL06, article_ref: "Art. 5(1)(f)" }
    - { clause_id: GDPR-CP15, article_ref: "Art. 32(1)(b)" }
    - { clause_id: GDPR-CL01, article_ref: "Art. 4(1) — personal data definition" }
  linked_objectives: [SO-GDPR-001, SO-GDPR-003]
  sub_domain: [D-01.1, D-01.4]
  nist_csf_mapping:
    ...
```
```

**Como parear:** dentro de cada bloco YAML, todos os `clause_id:` entre `source_clauses:` e o próximo `sub_domain:` mapeiam para a lista `sub_domain: [D-XX.Y, ...]` desse mesmo bloco.

**Implementação sugerida:**
```python
def parse_clause_to_subs(src: Path) -> dict[str, set[str]]:
    """Map clause_id -> set of sub_domain IDs, from all 5 regulations' SR files."""
    clause_to_subs: dict[str, set[str]] = defaultdict(set)
    for reg in REGULATIONS:
        sr_path = src / "Regulation" / reg / "02_SecurityRules_NIST.md"
        if not sr_path.exists():
            continue
        text = sr_path.read_text(encoding="utf-8")
        # Split into YAML fenced blocks.
        for block in re.findall(r"```yaml\n(.*?)\n```", text, re.DOTALL):
            # Collect clause_ids and the sub_domain list within this block.
            clause_ids = re.findall(r"clause_id:\s*([A-Za-z_]+-\w+)", block)
            sub_m = re.search(r"sub_domain:\s*\[([^\]]*)\]", block)
            if not sub_m:
                continue
            subs = re.findall(r"D-\d+\.\d+", sub_m.group(1))
            for cid in clause_ids:
                clause_to_subs[cid].update(subs)
    return clause_to_subs
```
Atenção: o regex `clause_id:\s*([A-Za-z_]+-\w+)` deve apanhar `GDPR-CL06`, `GDPR-CP15`, `CRA-D01`, etc. Testa e ajusta se faltar algum padrão.

### 4b. Parser B: partir ficheiros de Ambiguidade em secções por clause_id

**Fonte:** `methodology-00/PREPROCESSING/Regulation/{REG}/Ambiguity/*.md`

**Excluir:** `00_*_Index.md`, `99_*_Synthesis.md`, e legacy `NN_<REG>.md` (padrão `^\d{2}_[A-Za-z_]+\.md$` — já usado no script atual para `_archive/legacy/`).

### ⚠️ FORMATO DE clause_id DIVERGENTE ENTRE REGULAÇÕES (crítico)

**GDPR** (e provavelmente NIS2/DORA/AI_Act): clause_id numa linha própria após um header `####`:
```
#### Art. 5(1)(f) — Integrity and confidentiality

**Clause: GDPR-CL06** | type: principle | obligatedParty: CONTROLLER | obligationType: CONTINUOUS
```
Padrão regex: `\*\*Clause:\s*([A-Za-z_]+-[A-Za-z0-9]+)\*\*`

**CRA**: clause_id embutido no header `###`:
```
### 2.1 Definition (1) `product with digital elements` (CRA-D01)
```
Padrão regex: `\(([A-Z]+-D\d+)\)` no header.

**Estratégia robusta (múltiplos padrões com fallback):**

1. Parte o ficheiro em secções. Para GDPR-style, split por `^#### ` (h4). Para CRA-style, split por `^### \d+\.\d+ `. **Abordagem mais simples:** parte por TODOS os headers `^#{3,4} ` e tenta extrair clause_id de cada secção.
2. Para cada secção, tenta extrair clause_id por ordem:
   - `\*\*Clause:\s*([A-Za-z_]+-[A-Za-z0-9]+)\*\*` (GDPR bold-line)
   - `\(([A-Z]+-[A-Z]{1,3}\d+)\)` (CRA header-inline)
   - Fallback genérico: `\b([A-Z]+(?:_Act)?-[A-Z]{1,3}\d+)\b` (apanha `GDPR-CL06`, `CRA-D01`, `AI_Act-XX01`, etc.)
3. Se clause_id encontrado **e** está em `clause_to_subs` (Parser A), regista `(clause_id, sub_domains, section_text)`.

**Implementação sugerida:**
```python
def parse_ambiguity_sections(src: Path, clause_to_subs: dict) -> list[dict]:
    """Extract ambiguity sections keyed by clause_id. Returns list of
    {reg, clause_id, sub_domains: set, section_md: str}."""
    sections = []
    # Patterns for clause_id, tried in order.
    patterns = [
        re.compile(r"\*\*Clause:\s*([A-Za-z_]+-[A-Za-z0-9]+)\*\*"),
        re.compile(r"\(([A-Z]+-D\d+)\)"),
        re.compile(r"\b([A-Z]+(?:_Act)?-[A-Z]{1,3}\d+)\b"),
    ]
    for reg in REGULATIONS:
        amb_dir = src / "Regulation" / reg / "Ambiguity"
        if not amb_dir.exists():
            continue
        for md_file in sorted(amb_dir.glob("*.md")):
            # Skip index, synthesis, legacy.
            if re.match(r"^(00_|99_)", md_file.name):
                continue
            if re.match(r"^\d{2}_[A-Za-z_]+\.md$", md_file.name):
                continue
            text = md_file.read_text(encoding="utf-8")
            # Split into sections by headers ### or ####.
            parts = re.split(r"(?=^#{3,4}\s)", text, flags=re.MULTILINE)
            for part in parts:
                if not part.strip():
                    continue
                clause_id = None
                for pat in patterns:
                    m = pat.search(part)
                    if m:
                        clause_id = m.group(1)
                        break
                if clause_id and clause_id in clause_to_subs:
                    sections.append({
                        "reg": reg,
                        "clause_id": clause_id,
                        "sub_domains": clause_to_subs[clause_id],
                        "section_md": part.strip(),
                    })
    return sections
```

## 5. Reescrever `stage_domains()` — esqueleto

```python
def stage_domains(
    src: Path,
    dst: Path,
    article_map: dict[str, list[tuple[str, str]]],
    clause_to_subs: dict[str, set[str]],
    ambig_sections: list[dict],
    dry_run: bool,
    plan: list[str],
) -> dict[str, dict[str, int]]:
    sub_src = src / "SubDomains"
    da_src = src / "CrossRegulation" / "DomainAnalysis"
    de_src = src / "CrossRegulation" / "DeepAnalysis"
    stats: dict[str, dict[str, int]] = {}

    # Invert ambiguity sections into sub_domain -> [sections].
    sub_to_sections: dict[str, list[dict]] = defaultdict(list)
    for sec in ambig_sections:
        for sd in sec["sub_domains"]:
            sub_to_sections[sd].append(sec)

    for ddir in list_domain_dirs(sub_src):
        domain_name = ddir.name
        domain_dst = dst / "domains" / domain_name
        d_stats = {"subsubdomains": 0, "articles": 0, "ambiguity_sections": 0}

        for ss_file in list_subsubdomain_files(ddir):
            ss_id = ss_file.stem  # D-XX.Y
            ss_dst = domain_dst / ss_id

            # Read the 3 source files.
            sub_md = ss_file.read_text(encoding="utf-8")
            da_file = da_src / domain_name / ss_file.name
            de_file = de_src / domain_name / ss_file.name
            da_md = da_file.read_text(encoding="utf-8") if da_file.exists() else ""
            de_md = de_file.read_text(encoding="utf-8") if de_file.exists() else ""

            # Build Part 4: relevant ambiguity, grouped by regulation.
            relevant = sub_to_sections.get(ss_id, [])
            d_stats["ambiguity_sections"] += len(relevant)
            part4_parts = []
            secs_by_reg = defaultdict(list)
            for sec in relevant:
                secs_by_reg[sec["reg"]].append(sec)
            for reg in REGULATIONS:
                secs = secs_by_reg.get(reg, [])
                if secs:
                    body = "\n\n".join(_downgrade_headers(s["section_md"]) for s in secs)
                    part4_parts.append(f"## {reg}\n\n{body}")
                else:
                    part4_parts.append(f"## {reg}\n\n_No applicable {reg} ambiguity._")
            part4 = "\n\n".join(part4_parts)

            # Title: first h1 of subdomain.md, fallback to ss_id.
            title_m = re.search(r"^#\s+(.+)$", sub_md, re.MULTILINE)
            title = title_m.group(1).strip() if title_m else ss_id

            # Assemble merged file.
            merged = f"""# {ss_id} — {title}

> Unified view: Sub-domain definition + Domain Analysis + Deep Analysis + relevant Ambiguity.
> Generated by reorg_by_domain_md.py from PREPROCESSING/.

---

# Part 1 — Sub-domain definition

{_downgrade_headers(sub_md)}

---

# Part 2 — Domain Analysis (cross-regulation)

{_downgrade_headers(da_md) if da_md else "_Domain Analysis source not found._"}

---

# Part 3 — Deep Analysis (per-pair)

{_downgrade_headers(de_md) if de_md else "_Deep Analysis source not found._"}

---

# Part 4 — Relevant Ambiguity (by regulation)

{part4}
"""
            merged_path = ss_dst / f"{ss_id}.md"
            plan.append(f"  [merge] {ss_id} -> {merged_path}")
            if not dry_run:
                merged_path.parent.mkdir(parents=True, exist_ok=True)
                merged_path.write_text(merged, encoding="utf-8")

            # articles/ (same as before).
            for reg, art_name in sorted(article_map.get(ss_id, [])):
                a_src = src / "Regulation" / reg / "Articles" / f"{art_name}.md"
                if a_src.exists():
                    copy_file(a_src, ss_dst / "articles" / f"{reg}_{art_name}.md", dry_run, plan)
                    d_stats["articles"] += 1

            d_stats["subsubdomains"] += 1

        stats[domain_name] = d_stats
        log(f"  {domain_name}: {d_stats['subsubdomains']} sub-subdomains, "
            f"{d_stats['articles']} article copies, {d_stats['ambiguity_sections']} ambiguity sections")

    return stats
```

## 8. Armadilhas conhecidas (lê antes de começar)

1. **`grep` com locale:** neste ambiente, `grep` é um alias que dá erro "comparadores em conflito" com certas flags. **Usa sempre `command grep` ou `/usr/bin/grep`**, ou melhor, faz a validação em Python.

2. **Symlink `methodology-00`:** aponta para `Methodology-main/00_METHODOLOGY/`. Ao usar `.resolve()` no script, os paths absolutos mostrados incluem `Methodology-main/`. É o mesmo conteúdo — não te confunda.

3. **Nomes de ficheiros de articles com espaço** (em `preproc_out`, não aqui): neste pipeline de MDs os ficheiros são `Art_NN.md` (sem espaço). Não há problema aqui.

4. **Clause_id pode não bater entre regs:** CRA usa `CRA-D01` (header-inline), GDPR usa `GDPR-CL06` (bold-line). O `02_SecurityRules_NIST.md` é a fonte de verdade para o mapa clause_id → sub_domain; valida que os clause_ids extraídos dos ficheiros de Ambiguidade aparecem nesse mapa. Reporta a taxa de match por regulação no log. Se alguma reg tiver taxa muito baixa, documenta como limitação mas não bloqueies.

5. **Many-to-many é esperado:** uma secção com clause_id `GDPR-CL06` (mapeia a ~11 sub-domínios) aparece nos 11 ficheiros merged. Não é bug.

6. **YAML parsing:** não uses `yaml.load` (pode não estar disponível / é lento). Usa regex como no esqueleto acima. Os blocos têm formato regular.

7. **Headers no merge:** se um ficheiro fonte não tiver h1, o `_downgrade_headers` não lhe adiciona um — a estrutura fica com `## ...` no topo da parte, que é o pretendido (o h1 é o "Part N" do ficheiro merged).

8. **`_by_regulation/{REG}/Ambiguity/` mantém-se íntegro** (cópia verbatim da fase `stage_by_regulation`) — não o toques. É a fonte de verdade paralela.
